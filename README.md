# 🚀 AI Calculator Pro (v1.5.0)

A modern, sleek desktop calculator built with **Python** and **Tkinter**, featuring the gorgeous **Catppuccin** color theme, calculation history, and keyboard support.

---

## ✨ Features
- 🎨 **Modern UI:** Styled with the elegant Catppuccin theme (`#1e1e2e`).
- 📜 **Calculation History:** Keeps track of all your past calculations with an easy-to-use history sidebar and clear option.
- ⌨️ **Full Keyboard Support:** Type numbers, use operators, press `Enter` to calculate, and `Esc` to clear.
- 🔄 **Manual Update Checker:** Check for newer releases directly from GitHub securely.
- 🪟 **Resizable Window:** Smooth scaling interface with a defined minimum size.

---

## 🛠️ Tech Stack
- **Python** (Core Logic)
- **Tkinter** (Graphical User Interface)
- **PyInstaller** (Executable compilation)

---

## 📥 Installation & Running
1. Clone the repository:
   ```bash
   git clone [https://github.com/816400/calculator-app.git](https://github.com/816400/calculator-app.git)
   cd calculator-app
   ```
2. Run the Python script:
   ```bash
   python calculator.py
   ```
